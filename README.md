# Incursa Tooling

![Incursa Tooling banner](images/banner.png)

Incursa Tooling is a lightweight extension pack for specification traceability, repeatable CSV validation and comparison, auditable report authoring, and offline database knowledge. The pack contains metadata only; every member extension remains independently versioned, packaged, installable, and removable.

## Included extensions

| Extension | Web | Desktop | Repository |
|---|---:|---:|---|
| SpecTrace for VS Code | Yes | Yes | [incursa/spec-trace-vsce](https://github.com/incursa/spec-trace-vsce) |
| CSV Contract Workbench | Yes | Yes | [incursa/csv-contract-vsce](https://github.com/incursa/csv-contract-vsce) |
| Auditable Reports for VS Code | No web claim | Windows | [incursa/auditable-reports-vsce](https://github.com/incursa/auditable-reports-vsce) |
| Database Knowledge Workbench | Bounded bundle subset | Windows-first | [incursa/database-knowledge-vsce](https://github.com/incursa/database-knowledge-vsce) |

See the tracked [capability matrix](docs/capability-matrix.md) for exact boundaries and the [security and privacy model](docs/security-and-privacy.md) for portfolio defaults.

## Install

Install `incursa.incursa-tooling-vsce` from the Visual Studio Marketplace, install the packaged VSIX, or select it in Incursa Tooling Setup. The installer and each member product remain optional independent delivery paths.

## Privacy

The extension pack has no activation code, telemetry, network behavior, file access, or subprocess capability. Member extensions are offline-first and do not upload workspace content.
